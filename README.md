# Описание
Контроллер UART, написанный на SystemVerilog. Проект настроен и аппаратно протестирован на ПЛИС Altera/Intel Cyclone IV (EP4CE6E22C8). Отладочная плата: A-C4E6E10

## Характеристики
* **Язык:** SystemVerilog
* **Baudrate:** 115200 (параметризуется)
* **Тактовая частота (Clk):** 50 МГц
* **Формат пакета:** 1 стартовый бит, 8 бит данных, 1 стоповый бит, без бита четности.

## Структура проекта
* `src/` — исходные RTL-модули (генератор тактов, RX, TX, модуль подавления дребезга кнопок).
* `sim/` — Testbench для временного моделирования в Modelsim.
* `quartus/` — проект для Quartus Prime.

## Настройка Pin Planner (EP4CE6E22C8)
Сигналы настроены под I/O Standard `3.3-V LVTTL`. Перед прошивкой убедитесь, что пины в файле `.qsf` соответствуют вашей отладочной плате:
* `Clk` — PIN_23 (или PIN_25 в зависимости от платы)
* `rst_n` — аппаратная кнопка сброса (активный низкий)
* `i_tx_vld_button` — кнопка старта передачи (использует встроенный модуль debounce на 20 мс)

## Использование
1. Склонируйте репозиторий.
2. Откройте файл `quartus/Uart.qpf` в Quartus Prime.
3. При необходимости скорректируйте привязку пинов в Pin Planner.
4. Запустите *Compile Design*.
5. Зашейте сгенерированный файл `.sof` из папки `output_files` в ПЛИС через Programmer.
